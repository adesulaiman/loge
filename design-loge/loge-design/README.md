# Loge design export

Open `index.html` in a browser for the overview, or any page directly.

- `*.html` are static pages, one per screen (desktop and mobile, light and dark), plus the design tokens, logo, component notes and chat avatar sheets.
- `loge.css` holds the theme tokens (`data-theme="light|dark"`) and animation classes. Pages share it.
- `mark.svg`, `sky-light.svg`, `sky-dark.svg` are the logo and background art.
- `previews/` has a PNG of each page.
- `login-*.html` (Sign in / Create account) and `avatar-states.html` (state buttons) are still interactive.
- Fonts load from Google Fonts (Dela Gothic One, Zen Kaku Gothic New, Chakra Petch, JetBrains Mono), so open the files online for exact typography.
